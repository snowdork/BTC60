# ROLR BTC60 Terminal

Implementation of the supplied ROLR HTML and screenshot. Open `index.html`, or run `python3 -m http.server 8000` from this directory.

Includes persistent tier visibility, expand/collapse controls, stake selection, calculated returns, and simulated prediction feedback. Prices, balances, and settlements are reference demo data. No wallet or live trading backend is connected.

Tailwind CSS and fonts load from external CDNs and require an internet connection.
